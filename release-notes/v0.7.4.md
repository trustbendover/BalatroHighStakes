# Balatro High Stakes 0.7.4

- **Lobby.** An unchanged player list is not sent again. A list you ask for still arrives.
- **Scores.** The same score is not broadcast twice. A score Steam refused is sent again.
- **Lag.** Heartbeats are every 5 seconds, and 24 seconds of quiet still keeps you in the match.
- **Idle.** The game allocates less while the connection is quiet.

**Install:** download the Installer zip, unzip it, run `Install.bat`. Already on 0.6.6 or newer? Use the in-game "Update available" button or `Update.bat`.
