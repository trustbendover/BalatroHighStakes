# Balatro High Stakes 0.6.9

- **Host settings.** The host's match settings apply to everyone on join, at the start, and on rejoin. A setting the host does not send is off, not whatever the other player had locally. Personal display and audio choices stay on each computer.
- **Rematch.** When the match is over, the host can press Rematch (Opnieuw). The same lobby, teams and host settings stay. The run itself is cleared, and guests have to ready again. It is refused while a match is still going, and a guest cannot start it.
- **Public or private.** The host chooses on the general lobby-options tab. Private is the default. A private lobby is not marked for the lobby list and does not publish a friends-list Join game string. The lobby code and Steam invites still work. Public marks the lobby so the list can show it. The code is not a password.
- **Public lobby list.** From the multiplayer menu: host name, mode, players, and waiting or in progress. Join is for a waiting lobby with a free seat. Watch is for a match that is already running and still allows spectators. Other mods and other versions are not listed. Refresh and back. If a lobby is made private after it was listed, Join and Watch do not sit you down.
- **Deathmatch tests.** The automated Deathmatch leave checks follow the existing rule: Leave holds the seat for the grace window. That rule itself is unchanged.

The lobby list uses Steam's lobby search. This release was not tried against a live Steam network or the real game window. Code join, invites, and a private default were checked with the project's Steam stand-in.

**Install:** download the Installer zip, unzip it, run `Install.bat`. Already on 0.6.6 or newer? Use the in-game "Update available" button or `Update.bat`.
