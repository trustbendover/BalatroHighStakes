# Balatro High Stakes 0.7.2

The first hand is dealt again.

- **Round 1.** After you select the first blind, cards are dealt. This includes solo Gambel Time against The House, and a table spin of Wild Odds.
- **Retry.** The blind button is remembered, so you are not stuck with "No next blind context".

**Install:** download the Installer zip, unzip it, run `Install.bat`. Already on 0.6.6 or newer? Use the in-game "Update available" button or `Update.bat`.
