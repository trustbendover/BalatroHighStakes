# Balatro High Stakes 0.7.3

- **Chat.** It clears when a match starts, and again when everyone is back in the lobby. A rematch starts clean too.
- **Watch.** Follow a player and see their hand, jokers, consumables, score, money, and shop. Use Board and Stats to switch between the live table and the list.

**Install:** download the Installer zip, unzip it, run `Install.bat`. Already on 0.6.6 or newer? Use the in-game "Update available" button or `Update.bat`.
