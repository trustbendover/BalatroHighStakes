Balatro High Stakes  v0.7.0  (onofficiële fork van Balatro Multiplayer, door Trust Ben Dover)
==============================================================================================
Balatro Multiplayer voor 2 tot 8 spelers: 1v1 Duel, Attrition, Showdown, King of the Hill en
Teams (2v2, 3v3, 4v4, 2v2v2, 2v2v2v2). Iedereen in het spel heeft deze mod nodig.
(Voorheen "Balatro Multiplayer 3P"; de installatiemap heet nog BalatroMultiplayer3P.)
Windows + Steam-versie van Balatro.

ALLEEN STEAM: sinds 0.6.8 speelt Balatro High Stakes alleen via Steam peer-to-peer. Geen server, geen
IP-adres, geen playit.gg / Tailscale / port forwarding - de Balatro van de host is de server.

UPDATEN VANAF EEN OUDERE VERSIE: iedereen (host EN vrienden) moet 0.6.8 installeren. Draai gewoon
Install.bat opnieuw; hij vervangt de oude versie en houdt je instellingen. Speelde je eerder via een
serveradres? Dan zet de installer dat een keer om naar Steam, meldt dat, en bewaart je oude .env in de
backupmap.

INSTALLEREN
1. Sluit Balatro. Pak de hele zip uit (niet vanuit de zip starten).
2. Dubbelklik Install.bat.
   - Windows SmartScreen ("Windows heeft uw pc beschermd"): "Meer informatie" -> "Toch uitvoeren".
     Het is een gewoon batch/PowerShell-script; je kunt install.ps1 eerst lezen.
3. De installer zoekt Balatro, installeert Lovely (modloader), Steamodded 1.0.0~BETA-1620a en
   de High Stakes-mod, en maakt een backup van alles wat hij vervangt (%APPDATA%\Balatro\MP3P-backup-*).
4. Niets te kiezen: de mod speelt altijd via Steam (mode=steam).
5. Start Balatro gewoon via Steam. In het hoofdmenu staat 0.7.0.

UPDATES (vanaf 0.6.6)
- Bij een nieuwe versie staat er in het hoofdmenu (linksboven) een knop "Update available: vX".
  Klik erop en sluit Balatro: de updater downloadt de nieuwe Installer-zip van GitHub, controleert
  de SHA256, installeert hem (instellingen blijven) en zegt wanneer je Balatro weer kunt starten.
- Of start Update.bat (in deze map, of in %APPDATA%\Balatro\Mods\BalatroMultiplayer3P\updater).
- Releases: https://github.com/trustbendover/BalatroHighStakes/releases
- Update-check uitzetten: zet de regel update_check=false in het .env-bestand.

STEUN: vind je de mod leuk? https://ko-fi.com/trustbendover

SPELEN (STEAM)
- Iedereen kan hosten: Play -> Create Lobby. De Balatro van de host is de server, dus de host
  moet Balatro open laten tot het spel klaar is.
- Joinen met code: Play -> Join Lobby -> code typen. Wacht ~10 seconden nadat de host de lobby
  heeft gemaakt: Steam heeft even nodig voordat de lobby vindbaar is.
- EXPERIMENTEEL: knop "Invite Steam friend" in de lobby (Steam-overlay), en Steam-vriendenlijst
  -> rechtsklik op de host -> "Join game". Accepteren = joinen zonder code. Werkt het niet? Play -> "Join Steam invite again",
  of kopieer de code en kies "Join From Clipboard" (werkt ook met een Steam-lobby-id), of typ de code.
- Rejoin: verbinding kwijt of gecrasht? Start Balatro en join opnieuw met dezelfde code en
  dezelfde naam: je krijgt je plek, levens en ante terug (plek blijft vast tot het einde).
- Late join: een extra speler (tot 8) kan in een lopend spel komen (niet in 1v1 Duel of Teams);
  start op de laagste ante/levens en zit een blind die al bezig is uit.

PROBLEMEN
- Spel start niet / geen "Mods"-knop: een oude Lovely "version.dll" in de Balatro-map botst met
  Lovely 0.10 (winmm.dll). De installer haalt hem weg (met backup).
- Crash in overrides.lua: verkeerde Steamodded-versie. Nodig: precies 1.0.0~BETA-1620a;
  draai Install.bat opnieuw.
- "No Steam lobby found": 10 s wachten en opnieuw; code checken; host moet nog in de lobby zitten.
- "Steam-multiplayer niet klaar" in het hoofdmenu: start Balatro via Steam (Steam moet draaien) en
  druk op Reconnect / Opnieuw verbinding maken.
- Logs: %APPDATA%\Balatro\Mods\lovely\log\ (nieuwste bestand), zoek op "Steam P2P".
- Officiele Balatro Multiplayer ook geinstalleerd (mappen met mod-id Multiplayer, MultiplayerPvP,
  MultiplayerAPI)? Die botsen met High Stakes (zelfde id / zelfde "mp"-prefix). Install.bat toont ze en
  zet ze in de backupmap als je J/Y zegt (er wordt niets verwijderd). Uninstall.bat zet ze terug.
  Het spel waarschuwt ook bij het opstarten ("Let op: nog een Multiplayer-mod").
- Verwijderen: Uninstall.bat zet de backups terug.
